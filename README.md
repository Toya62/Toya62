- 💼 **Industry Background**:

  - Assisted & Automated Driving (AAD) Werkstudent & Intern @ **Continental** (C++ DTC diagnostic tooling for ECU fault codes, Raspberry Pi embedded Linux video test systems, Jenkins CI/CD).
  - Software Developer Werkstudent @ **GWQ ServicePlus AG** (Python/C++ Qt GUI tools, testing & CI/CD).
  - Security Analyst @ **Security Innovation** (OWASP pentesting, ELK/Kibana SIEM log analysis, network security).
- 🌍 **Languages**: English (C1 Fluent) | German (B2 Active Development)
